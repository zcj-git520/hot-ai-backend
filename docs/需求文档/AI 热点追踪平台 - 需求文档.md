## 1. 项目概述

### 1.1 产品愿景

> **帮助普通人理解 AI、应对 AI、利用 AI**

在 AI 技术快速发展的时代，普通人面临信息过载和职业焦虑的双重压力。本平台致力于成为 AI 时代的职业导航仪，帮助用户：
- 了解 AI 最新动态
- 评估职业风险
- 获得学习指引
- 实现职业转型

### 1.2 产品定位

| 维度 | 定位 |
|------|------|
| **目标用户** | 职场焦虑人群 + 学习探索者（两者兼顾） |
| **核心价值** | 资讯 + 影响分析 + 行动指南 的完整闭环 |
| **差异化** | 不做纯资讯聚合，做"AI 时代的职业导航" |
| **商业模式** | 免费 + 广告（后期扩展付费订阅、企业服务等） |
| **平台优先级** | Web 端优先，后续考虑移动端 |

### 1.3 产品名称（待定）

备选名称：
- AI 风向标
- 职 AI 导航
- AI 生存指南
- 智变追踪

### 1.4 项目原则

1. **长期主义**：不追求短期流量，注重长期价值
2. **用户第一**：真正帮助用户解决问题
3. **内容质量**：宁缺毋滥，深度优于数量
4. **快速迭代**：小步快跑，根据反馈持续优化
5. **技术驱动**：善用 AI 提效，但不依赖 AI

## 2. 用户分析

### 2.1 目标用户画像

#### 用户类型 A：职场焦虑型

```
基本信息：
- 年龄：25-45 岁
- 职业：运营、设计、文案、客服、数据录入等
- 收入：中等
- 教育：大专及以上

特征：
- 担心被 AI 取代
- 碎片化阅读 AI 新闻
- 焦虑但不知如何行动
- 时间有限（下班后学习）

核心需求：
- 了解自己的职业风险等级
- 知道具体哪些任务会被替代
- 获得清晰的转型路径
- 有人陪伴学习（社区）

典型场景：
"看到 AI 取代岗位的新闻，心里紧张，
想深入了解但找不到系统分析，
想学习但不知道从哪开始"
```

#### 用户类型 B：学习探索型

```
基本信息：
- 年龄：18-35 岁
- 身份：学生/转行者/自我提升者
- 职业：不限
- 教育：不限

特征：
- 对 AI 感兴趣
- 想系统学习但缺乏指引
- 担心被割韭菜
- 需要实践项目

核心需求：
- 清晰的学习地图
- 优质资源推荐
- 实战项目指导
- 学习进度追踪

典型场景：
"想进入 AI 领域，但非计算机专业，
看了很多教程太零散，无法形成体系，
迷茫：到底该学什么？"
```

#### 用户类型 C：企业管理者（次要用户）

```
基本信息：
- 年龄：35-55 岁
- 身份：中小企业主/团队领导
- 关注：降本增效

核心需求：
- 同行业 AI 应用案例
- ROI 分析
- 工具推荐 + 实施指南
```


### 5.3 关键技术决策

#### 决策 1：Monorepo vs 分离仓库

**选择**：Monorepo (pnpm workspace)

**理由**：
- 代码共享方便（类型、工具函数）
- 统一依赖管理
- 原子提交
- 适合中小团队

#### 决策 2：Next.js API Routes vs 独立后端

**选择**：混合架构

**理由**：
- 简单 API 用 Next.js API Routes（BFF 模式）
- 复杂服务（抓取、SSE）用独立 Fastify 服务
- 平衡开发效率和系统解耦

#### 决策 3：SSE vs WebSocket

**选择**：SSE (Server-Sent Events)

**理由**：
- 单向推送足够（服务端→客户端）
- 实现简单
- 自动重连
- 资源消耗低
- 原生支持

#### 决策 4：PostgreSQL vs MongoDB

**选择**：PostgreSQL

**理由**：
- 数据结构相对固定
- 需要复杂查询
- 事务支持
- JSONB 支持灵活字段
